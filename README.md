# F1 Qualifying Forecast

Published Formula 1 qualifying forecasts and race reviews.

This repository contains only generated website assets and selected published
content. The prediction model is maintained separately. Do not edit generated
assets here: update the source project and republish.

GitHub Pages: https://Yu-Shin-Huang.github.io/f1-quali-website/

## Hosting

In Settings > Pages, choose **Deploy from a branch**, branch **main**, folder
**/(root)**. The `.nojekyll` file makes this a plain static website.

Experimental independent analysis; not affiliated with Formula 1 or the FIA.
